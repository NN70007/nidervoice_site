Installation

Le paquet MSI installe NiderVoice pour tous les utilisateurs, dans Program Files. Les utilisateurs n'ont pas besoin de droits d'administrateur pour s'en servir.

  • Installation silencieuse : msiexec /i NiderVoice-<version>.msi /qn
  • Désinstallation : msiexec /x NiderVoice-<version>.msi /qn ou « Applications installées ».
  • Le code de mise à niveau du MSI est stable d'une version à l'autre : une nouvelle version remplace proprement l'ancienne.
  • Un MSI standard se déploie avec vos outils habituels : Intune, Configuration Manager, stratégie de groupe.

Signature du code En cours
La signature Authenticode du programme est en cours d'obtention. D'ici là, Windows affiche « Éditeur inconnu ». Pour autoriser le logiciel avec précision (AppLocker, WDAC, antivirus), utilisez les empreintes SHA-256 fournies avec chaque version.

Installation

The MSI package installs NiderVoice for all users, in Program Files. Users do not need administrator rights to use it.

  • Silent install: msiexec /i NiderVoice-<version>.msi /qn
  • Uninstall: msiexec /x NiderVoice-<version>.msi /qn or "Installed apps".
  • The MSI upgrade code is stable across versions: a new version cleanly replaces the old one.
  • A standard MSI deploys with your usual tools: Intune, Configuration Manager, Group Policy.

Code signing In progress
Authenticode signing of the program is being obtained. Until then, Windows shows "Unknown publisher". To allow the software precisely (AppLocker, WDAC, antivirus), use the SHA-256 fingerprints supplied with each version.

Matrice réseau

Pour un environnement sensible, nous recommandons l'édition sans réseau. Son comportement réseau tient en un tableau :

FonctionÉdition sans réseau
Reconnaissance vocaleLocale
Recherche de mises à jourAbsente
Téléchargement de modèlesAbsent : modèles livrés avec l'installation
Services d'IA en ligneAbsents
Télémétrie, licence en ligneAbsentes
Connexions mesurées (TCP, UDP, DNS)Aucune

Les autres éditions peuvent rechercher les mises à jour et télécharger les modèles de la liste fermée, vérifiés par empreinte ; ces fonctions se désactivent.

Dans l'édition sans réseau, les fonctions de connexion ne sont pas seulement désactivées : le code qui pourrait se connecter refuse de s'exécuter. Le composant WebView2 est lancé avec ses services d'arrière-plan coupés (SmartScreen, mises à jour de composants, préchargement DNS, rapports).

Network matrix

For a sensitive environment we recommend the offline edition. Its network behaviour fits in one table:

FunctionOffline edition

Other editions can check for updates and download closed-list models, verified by fingerprint; these features can be turned off.

In the offline edition, connection features are not just disabled: the code that could connect refuses to run. The WebView2 component is started with its background services turned off (SmartScreen, component updates, DNS prefetch, reporting).

Accès utilisés sur le poste

Un logiciel de dictée doit écouter un raccourci et écrire dans d'autres applications. Ces comportements peuvent alerter un antivirus comportemental ; ils sont communs à tous les logiciels de dictée. Voici la liste complète :

  • Micro : seulement pendant la dictée.
  • Raccourci clavier global et clic du milieu de la souris : seules ces touches sont surveillées.
  • Collage simulé (Ctrl+V) ou frappe directe dans la fenêtre active.
  • Presse-papiers : texte marqué pour être exclu de l'historique, de la synchronisation cloud et des logiciels de surveillance, puis effacé une seconde après le collage.
  • UI Automation de Windows : pour repérer le champ où écrire quand l'utilisateur ancre la dictée sur un champ. Rien n'est lu au-delà du champ visé, rien n'est transmis.

Access used on the device

Dictation software has to listen for a shortcut and write into other applications. These behaviours may alert a behavioural antivirus; they are common to all dictation software. Here is the complete list:

  • Microphone: only while dictating.
  • Global keyboard shortcut and middle mouse button: only these keys are watched.
  • Simulated paste (Ctrl+V) or direct typing into the active window.
  • Clipboard: text flagged to be excluded from history, cloud sync and monitoring software, then cleared one second after pasting.
  • Windows UI Automation: to find the field to write into when the user anchors dictation to a field. Nothing beyond the target field is read, nothing is transmitted.

Vérifier vous-même l'absence de connexion

Lancez NiderVoice, dictez quelques phrases, puis exécutez ces commandes dans PowerShell. Elles listent toutes les connexions du programme et de ses sous-processus, y compris WebView2. Le résultat attendu est vide.

Verify there is no connection yourself

Start NiderVoice, dictate a few sentences, then run these commands in PowerShell. They list every connection of the program and its child processes, WebView2 included. The expected result is empty.

$all = Get-CimInstance Win32_Process
$ids = @(($all | Where-Object Name -like 'nidervoice*.exe').ProcessId)
do { $n = $ids.Count
     $ids += @($all | Where-Object { $ids -contains $_.ParentProcessId -and $ids -notcontains $_.ProcessId }).ProcessId
} while ($ids.Count -gt $n)
Get-NetTCPConnection | Where-Object { $ids -contains $_.OwningProcess }
Get-NetUDPEndpoint   | Where-Object { $ids -contains $_.OwningProcess }

For defence in depth, you can also block all outbound connections of the program in Windows Firewall:

New-NetFirewallRule -DisplayName "NiderVoice - sortant bloque" -Direction Outbound `
  -Program "C:\Program Files\NiderVoice\nidervoice.exe" -Action Block

Stratégies recommandées

  • Chiffrement du disque (BitLocker) et verrouillage de session : ils protègent les documents produits, que NiderVoice ne stocke pas lui-même.
  • Synchronisation du presse-papiers entre appareils : NiderVoice exclut déjà son texte, mais vous pouvez la désactiver pour tout le poste par stratégie de groupe.
  • Accès au micro : autorisez les applications de bureau à utiliser le micro, en limitant les autres applications selon votre politique.
  • Règles d'exécution (AppLocker, WDAC) : autorisez NiderVoice par son empreinte, puis par son certificat une fois la signature disponible.

Modèles de stratégie NiderVoice (ADMX) En développement : pour imposer depuis votre console les modèles autorisés, les réglages et les fonctions disponibles.

Recommended policies

  • Disk encryption (BitLocker) and session locking: they protect the documents produced, which NiderVoice does not store itself.
  • Clipboard sync across devices: NiderVoice already excludes its text, but you can disable it for the whole workstation via Group Policy.
  • Microphone access: allow desktop apps to use the microphone, restricting other apps according to your policy.
  • Execution rules (AppLocker, WDAC): allow NiderVoice by fingerprint, then by certificate once signing is available.

NiderVoice policy templates (ADMX) In development: to enforce allowed models, settings and available features from your console.

Versions et empreintes

Chaque version est livrée avec :

  • l'empreinte SHA-256 du programme d'installation ;
  • la liste des empreintes SHA-256 de tous les fichiers installés ;
  • une fiche de version pour le service informatique.

L'édition sans réseau ne se met jamais à jour seule : c'est votre service informatique qui déploie chaque nouvelle version, après l'avoir contrôlée.

Versions and fingerprints

Each version ships with:

  • the SHA-256 fingerprint of the installer;
  • the list of SHA-256 fingerprints of all installed files;
  • a release sheet for the IT department.

The offline edition never updates itself: your IT department deploys each new version after checking it.
