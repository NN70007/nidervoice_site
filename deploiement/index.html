L'application MSI, pour les parcs gérés

Il s'agit de la forme de référence pour une organisation. Le paquet s'installe pour tous les utilisateurs, dans un dossier qu'ils ne peuvent pas modifier, et se déploie avec les outils en place. L'édition sans réseau retire du programme toute fonction de connexion : pas de mise à jour automatique, pas de téléchargement, pas de télémétrie.

  • Installation silencieuse, mise à niveau propre d'une version à l'autre.
  • Modèles livrés avec l'installation et vérifiés au chargement.
  • Écrit directement dans le logiciel métier, la messagerie ou le traitement de texte, au curseur.
  • Ancrage : la dictée peut être fixée sur un champ et continuer à s'y écrire pendant que l'utilisateur travaille ailleurs.

Détails techniques : kit informatique.

The MSI application, for managed fleets

This is the reference form for an organisation. The package is installed for all users, in a folder they cannot modify, and is deployed with the tools already in place. The offline edition removes every connection function from the program: no automatic update, no download, no telemetry.

  • Silent installation, clean upgrade from one version to the next.
  • Models shipped with the installation and verified at load time.
  • Writes straight into business software, e-mail or the word processor, at the cursor.
  • Anchoring: dictation can be pinned to a field and keep writing there while the user works elsewhere.

Technical details: IT kit.

La aplicación MSI, para flotas gestionadas

Se trata de la forma de referencia para una organización. El paquete se instala para todos los usuarios, en una carpeta que no pueden modificar, y se despliega con las herramientas existentes. La edición sin red elimina del programa toda función de conexión: sin actualización automática, sin descargas, sin telemetría.

  • Instalación silenciosa, actualización limpia de una versión a la siguiente.
  • Modelos enviados con la instalación y verificados en el momento de la carga.
  • Escribe directamente en el software empresarial, el correo electrónico o el procesador de textos, en el cursor.
  • Anclaje: el dictado puede fijarse a un campo y seguir escribiendo allí mientras el usuario trabaja en otro lugar.

Detalles técnicos: kit de informática.

Die MSI-Anwendung für verwaltete Geräteflotten

Dies ist die Referenzform für eine Organisation. Das Paket wird für alle Benutzer in einem Ordner installiert, den sie nicht verändern können, und mit den vorhandenen Werkzeugen bereitgestellt. Die netzwerklose Edition entfernt jede Verbindungsfunktion aus dem Programm: keine automatische Aktualisierung, kein Download, keine Telemetrie.

  • Unbeaufsichtigte Installation, sauberes Upgrade von einer Version zur nächsten.
  • Modelle, die mit der Installation geliefert und beim Laden überprüft werden.
  • Direktes Schreiben in Geschäftssoftware, E-Mail oder Textverarbeitung, am Cursor.
  • Verankerung: Diktat kann an einem Feld angeheftet werden und dort weiter schreiben, während der Benutzer anderswo arbeitet.

Technische Details: IT-Kit.

La version web, sans installation

Contrairement à la plupart des services de dictée en ligne, la version web de NiderVoice n'envoie pas la voix à un serveur. La page télécharge le modèle une fois, puis la reconnaissance se fait dans le navigateur, sur le poste. Le texte s'affiche en direct dans la page, d'où l'utilisateur le copie.

  • Navigateur récent (Chrome, Edge) ; pas de droits d'installation nécessaires.
  • La page interdit au navigateur d'envoyer des données ailleurs que vers son propre serveur, et n'envoie ni la voix ni le texte.
  • Sur l'intranet de l'organisation En préparation : l'organisation héberge elle-même la page et le modèle. Elle maîtrise alors le code servi à ses postes, ce qu'un service hébergé par un tiers ne permet pas.

The web version, with no installation

Unlike most online dictation services, the NiderVoice web version does not send the voice to a server. The page downloads the model once, then recognition runs in the browser, on the device. The text appears live in the page, from which the user copies it.

  • Recent browser (Chrome, Edge); no installation rights needed.
  • The page forbids the browser from sending data anywhere other than its own server, and sends neither the voice nor the text.
  • On the organisation's intranet In preparation: the organisation hosts the page and the model itself. It thereby controls the code served to its workstations, which a service hosted by a third party does not allow.

La versión web, sin instalación

A diferencia de la mayoría de los servicios de dictado en línea, la versión web de NiderVoice no envía la voz a un servidor. La página descarga el modelo una vez, luego el reconocimiento se ejecuta en el navegador, en el dispositivo. El texto aparece en vivo en la página, desde la cual el usuario lo copia.

  • Navegador reciente (Chrome, Edge); no se necesitan derechos de instalación.
  • La página impide que el navegador envíe datos a cualquier lugar distinto de su propio servidor, y no envía ni la voz ni el texto.
  • En la intranet de la organización En preparación: la propia organización aloja la página y el modelo. Controla así el código servido a sus puestos, algo que un servicio alojado por un tercero no permite.

Die Webversion, ohne Installation

Im Gegensatz zu den meisten Online-Diktierdiensten sendet die NiderVoice-Webversion die Stimme nicht an einen Server. Die Seite lädt das Modell einmal herunter, dann läuft die Erkennung im Browser auf dem Gerät. Der Text erscheint live auf der Seite, von der der Nutzer ihn kopiert.

  • Aktueller Browser (Chrome, Edge); keine Installationsrechte erforderlich.
  • Die Seite verbietet dem Browser, Daten an einen anderen Ort als ihren eigenen Server zu senden, und sendet weder die Stimme noch den Text.
  • Im Intranet der Organisation In Vorbereitung: Die Organisation hostet Seite und Modell selbst. Damit kontrolliert sie den an ihre Arbeitsplätze ausgelieferten Code, was ein von Dritten gehosteter Dienst nicht ermöglicht.

La version portable sur clé USB

Pour les consultants, les missions, les laboratoires isolés ou les postes où rien ne peut être installé. Le programme et ses modèles tiennent sur une clé et fonctionnent sans connexion. Les modèles restent vérifiés à chaque chargement.

De nombreuses organisations bloquent les clés USB, à juste titre. Sur un parc géré, le MSI est à privilégier. En cas d'utilisation de la clé, son chiffrement est recommandé : un tel support peut être perdu.

The portable version on a USB key

For consultants, assignments, isolated labs or devices where nothing can be installed. The program and its models fit on a key and work offline. Models are still verified at every load.

Many organisations block USB drives, and rightly so. On a managed fleet, the MSI is to be preferred. Where the drive is used, encrypting it is recommended: such a medium can be lost.

La versión portátil en una memoria USB

Para consultores, asignaciones, laboratorios aislados o dispositivos donde no se puede instalar nada. El programa y sus modelos caben en una memoria USB y funcionan sin conexión. Los modelos siguen verificándose en cada carga.

Numerosas organizaciones bloquean las memorias USB, con razón. En un parque gestionado, debe preferirse el MSI. Si se utiliza la memoria, se recomienda cifrarla: un soporte de este tipo puede perderse.

Die tragbare Version auf einem USB-Stick

Für Berater, Aufträge, isolierte Labore oder Geräte, auf denen nichts installiert werden kann. Das Programm und seine Modelle passen auf einen Stick und funktionieren offline. Die Modelle werden dennoch bei jedem Laden überprüft.

Viele Organisationen sperren USB-Sticks, und das zu Recht. Auf einer verwalteten Flotte ist das MSI vorzuziehen. Wird der Stick verwendet, empfiehlt sich seine Verschlüsselung: Ein solcher Datenträger kann verloren gehen.

Commencer par un projet pilote

Un démarrage à périmètre réduit est recommandé :

  1. Le DPO et le service informatique examinent les kits de sécurité.
  2. Le service informatique vérifie l'absence de connexion sur un poste de test.
  3. Quelques utilisateurs dictent pendant plusieurs semaines dans leurs logiciels habituels.
  4. L'organisation décide du déploiement au vu de leurs retours.

Start with a pilot

A start on a limited scope is recommended:

  1. The DPO and the IT department review the security kits.
  2. IT verifies there are no connections on a test device.
  3. A few users dictate for several weeks in their usual software.
  4. The organisation decides on deployment in the light of their feedback.

Comience con un piloto

Se recomienda un inicio con un perímetro reducido:

  1. El DPO y el departamento de informática examinan los kits de seguridad.
  2. El departamento de informática verifica que no hay conexiones en un dispositivo de prueba.
  3. Unos pocos usuarios dictan durante varias semanas en su software habitual.
  4. La organización decide el despliegue a la vista de sus valoraciones.

Beginnen Sie mit einem Pilotprojekt

Empfohlen wird ein Einstieg in begrenztem Umfang:

  1. Der Datenschutzbeauftragte und die IT-Abteilung prüfen die Sicherheitskits.
  2. Die IT prüft, ob auf einem Testgerät keine Verbindungen bestehen.
  3. Einige Nutzer diktieren mehrere Wochen lang in ihrer üblichen Software.
  4. Die Organisation entscheidet auf Grundlage ihrer Rückmeldungen über die Bereitstellung.
